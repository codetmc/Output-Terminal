How to Use Guide

  • A4 Document Sizing: The output page matches standard A4 portrait dimensions ($210\text{mm} \times 297\text{mm}$) for pristine PDF printouts and image exports.
  • Drag and Drop: Click and hold any terminal box to reorder its position on the grid.
  • Separate Terminal Windows: Type === on a new line in the editor to split content into individual output boxes.
  • Auto-Resizing Boxes: Heights expand or shrink automatically according to content length.
  • Direct Box Editing: Click directly inside any terminal box on screen to edit text in real time.
  • Add or Remove: Click + Add New Box to add blank boxes, or click × to remove a box.
